# u-rei.com-contents

`contents.u-rei.com` で公開する静的コンテンツ・独立プロジェクトを集約・ホスティングするリポジトリです。

## 概要
- **公開URL**: https://contents.u-rei.com/
- **DNS管理**: [kuchida1981/u-rei-infra](https://github.com/kuchida1981/u-rei-infra)
- **ホスティング**: GitHub Pages (Custom domain: `contents.u-rei.com`)

## ディレクトリ構成
- `CNAME`: カスタムドメイン定義 (`contents.u-rei.com`)
- `index.html`: 各コンテンツへのポータル画面
- `matt-cardona-vs-nick-gage-ja-subs/`: 「The Untold Story of Matt Cardona vs. Nick Gage (日本語字幕)」コンテンツ
  - ※ 個別リポジトリ `kuchida1981/matt-cardona-vs-nick-gage-ja-subs` から GitHub Actions で自動同期されます。
- `(新規プロジェクト)/`: 今後追加されるコンテンツ
